# Jaque Medeiros — site institucional

Site institucional da campanha de Jaque Medeiros, candidata a deputada estadual pelo PT em Campinas, São Paulo.

## Conteúdo

Textos baseados em fontes públicas (FAPESP, Labjor/Unicamp, TSE). Canais oficiais, número de urna e link de doação entram somente após confirmação da equipe.

## Desenvolvimento

```bash
npm run dev
```

Não alterar DNS de jaquemedeirospt.com.br nesta etapa.
