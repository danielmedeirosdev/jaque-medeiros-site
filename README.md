# Jaque Medeiros — site institucional

Arquivo editorial da trajetória de Jaqueline de Campos Medeiros.

## Conteúdo

Nada inventado. Lacunas usam `[CONTEÚDO A DEFINIR]`, `[FOTO A DEFINIR]` ou `[LINK A DEFINIR]`.

Textos, cargos, projetos, links e dados financeiros só entram depois de confirmação da equipe. Título acadêmico (mestrado/doutorado) está em revisão.

## Desenvolvimento

```bash
npm run dev
```

Não alterar DNS de jaquemedeirospt.com.br nesta etapa.
