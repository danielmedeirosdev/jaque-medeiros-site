# Jaque Medeiros — site institucional

Site institucional desenvolvido para organizar e apresentar a trajetória, o manifesto, os projetos e os canais oficiais de Jaqueline de Campos Medeiros.

[Visitar o site](https://www.jaquemedeirospt.com.br)

## Sobre o projeto

A experiência foi construída com uma arquitetura orientada a conteúdo, permitindo manter textos e informações estruturados sem depender de um CMS. O projeto prioriza clareza editorial, responsividade, acessibilidade e manutenção simples.

## Destaques

- Navegação responsiva para diferentes dispositivos
- Conteúdo estruturado e tipado
- Páginas institucionais e manifesto em PDF
- Galeria de imagens com visualização ampliada
- Integrações com Instagram, WhatsApp e e-mail
- Metadados e fundamentos de SEO técnico
- Deploy contínuo na Vercel

## Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS 4
- ESLint
- Vercel

## Desenvolvimento local

```bash
npm install
npm run dev
```

A aplicação estará disponível em `http://localhost:3000`.

## Comandos

```bash
npm run dev    # ambiente de desenvolvimento
npm run build  # build de produção
npm run start  # servidor de produção
npm run lint   # análise estática
```

## Integridade editorial

O conteúdo publicado deve ser baseado em informações confirmadas pela equipe responsável. Lacunas permanecem identificadas com marcadores como `[CONTEÚDO A DEFINIR]`, `[FOTO A DEFINIR]` ou `[LINK A DEFINIR]` até a validação.
